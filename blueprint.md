# **App Name**: SymphoKeys

## Core Features:

- Key-to-Note Mapping: Assign a unique musical note to each alphabet key.
- Auditory Feedback: Play the corresponding musical note upon pressing a key.
- Visual Feedback: Provide a glowing effect or highlight to indicate the active/pressed key.
- Scales Selection Tool: Allow users to select from different scales and modes to map to the keyboard, constraining the notes that are available.
- Instrument Sound Selection: Allow the user to select the type of instrument whose sounds will be emitted (piano, strings, synth, etc.)
- Preset Configuration Recommendations: AI tool suggest customized instrument and scale settings based on user input of the type of music they want to make.

## Style Guidelines:

- Background: Dark, near-black background (#121212) for a sleek look.
- Primary: Subtle glowing accent color (#94A3B8) to highlight active elements. 
- Accent: A brighter, desaturated hue (#BBC7D6) will contrast with the primary color in the display, providing readability.
- Font: 'Inter', a sans-serif font, for a modern and clean interface.
- Use minimalist icons for settings and instrument selection.
- Use smooth, subtle animations for key press feedback. Transition between states should be seamless.
- Keep the interface clean and uncluttered, focusing on usability and a visually appealing aesthetic.
